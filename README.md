# EduTrack Pro - Student Attendance Management System

A modern, feature-rich web-based attendance management system built for colleges and institutions to track student attendance, analyze performance, and manage defaulters efficiently.

## 🚀 Features
- **Interactive Dashboard:** Real-time analytics with Chart.js.
- **Mark Attendance:** Quick Present/Absent/Leave toggle per student or bulk actions.
- **Smart QR / Biometric Simulation:** Simulated live scanner for fast attendance entry.
- **Defaulter List (<75%):** Automated tracking of students falling below the 75% attendance criteria.
- **CSV Report Export:** Download attendance sheets instantly.
- **Dark Mode Support:** Seamless toggle between light and dark themes.
- **LocalStorage Persistence:** Data remains saved in your browser storage.

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- Chart.js
- FontAwesome & Google Fonts
