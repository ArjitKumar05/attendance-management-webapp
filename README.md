# 🎓 EduTrack Pro
### Smart Student Attendance Management System

A modern, responsive web application designed to simplify student attendance management for colleges and educational institutions.

🚀 **Live Demo:** [Launch EduTrack Pro](https://arjitkumar05.github.io/attendance-management-webapp/)

---

## ✨ Features

- 📊 **Interactive Dashboard** — Attendance statistics and Chart.js visualizations.
- 📋 **Attendance Management** — Mark students Present (P), Absent (A), or Leave (L).
- 👨‍🎓 **Student Management** — Manage student profiles and related information.
- 🔍 **QR / Biometric Scanner Simulation** — Animated scanner interface and scan audit log.
- ⚠️ **Defaulter Tracking** — Identify students with attendance below 75%.
- 📂 **CSV Export** — Download attendance reports.
- 🌙 **Dark Mode** — Switch between light and dark themes.
- 💾 **LocalStorage Persistence** — Save attendance data in the browser.
- 📱 **Responsive Design** — Interface for desktop, tablet, and mobile devices.

## ⚙️ How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/arjitkumar05/attendance-management-webapp.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser or run it using the Live Server extension.

No backend or database setup is required for the browser-based version.

## 🔐 Data Storage

- Data is stored locally in the browser using `localStorage`.
- Records are not automatically synchronized between devices.
- Clearing browser data may remove saved records.
- QR/biometric scanning and parent SMS alerts are simulations unless connected to real services.
